# 纯视觉街景定位系统

输入一张无元数据的街景图（全景或单张透视截图），输出中国县级概率分布，并给出期望得分最高的坐标。

**当前阶段：规划完成，尚未实现。**

## 文档

- [PLAN.md](PLAN.md) —— 完整实施方案：数据管线、模型设计、选点方法、里程碑、风险
- [prompt.md](prompt.md) —— 最初的需求描述

## 一句话摘要

两条线索（环境 / 文字）分别输出县级分布，融合后按真实街景点位求加权几何中位数选点。
当前规模 3 万条，主省四川，采集端在本地，训练在 Colab 免费档，文字线索延后至第二阶段。

## 数据约定

本仓库**只含代码与文档**。街景图像、数据库、训练产物和密钥全部由 `.gitignore` 排除。
密钥类文件另存脱敏的 `.example` 版本供参考。详见 [PLAN.md](PLAN.md) §4.4。
